# 迁移验收清单

本文用于确认 Tkinter 版本的关键行为已经迁入 Vue 3 + Tauri + Python sidecar。自动测试通过只代表数据契约和调度逻辑稳定；涉及 Windows 输入、游戏窗口、UAC 和网络监听的条目必须完成实机验收。

## 运行自动验收

在项目根目录执行：

```powershell
python -m unittest discover -s tests -v
npm --prefix frontend run test -- --run
npm --prefix frontend run typecheck
npm --prefix frontend run build
```

验收结果必须同时满足：

| 检查 | 通过条件 |
| --- | --- |
| Python 回归测试 | 全部通过，无失败或错误 |
| Vue 组件测试 | 全部通过 |
| TypeScript | `vue-tsc` 无错误 |
| 生产构建 | Vite 构建完成 |
| Git 隐私检查 | 配置、歌单、模板、捕获结果和真实令牌未进入提交 |

## 实机验收流程

### 验收目标与输入

1. 启动 `npm run dev`。
2. 在设置中选择目标窗口并执行连接检查与后台截图。
3. 在目标库分别验证 F8 点位、十字线预览、区域选择和图像识别。
4. 用一个无副作用工作流验证前台输入，再切换窗口消息模式验证后台点击。
5. 运行包含等待、图像点击、普通点击和失败回退的短队列。
6. 分别测试暂停、继续、停止与 F9 急停，并确认按键抬起和鼠标状态已清理。

### 验收剧组站

1. 打开游戏并进入剧组站。
2. 打开 Macro Studio 的“剧组”页面并允许一次 UAC。
3. 在游戏内搜索一个作品，等待监听状态变为“参数已捕获并验证”。
4. 确认作品封面、作者、时长、热度、收藏和喜欢数正常显示。
5. 切换单人、多人、映画分类，并验证名称匹配与热度排序。
6. 将作品加入一个非空队列，返回队列页确认名称、关键词和时长。
7. 关闭游戏后运行高级诊断，确认摘要、结论和完整报告均可读取和复制。

## 迁移边界

以下旧版实验入口不属于当前稳定发布面：

| 实验入口 | 处理 |
| --- | --- |
| 候选 URL / payload 桥接实验 | 保留在 Tkinter legacy 版本，不迁入主工作流 |
| `workId` 二维码研究入口 | 保留为研究工具，待确认真实价值后再决定是否产品化 |
| 直接注入或调用游戏内部方法 | 不进入稳定版迁移范围 |

阶段 4 的关闭条件是本页所有“待实机验收”条目完成验证。之后进入阶段 5：独立 Python sidecar、OpenCV 与 WinDivert 依赖打包、NSIS 安装包和升级回滚验证。
